# Statistical plots

These builders cover distributions, comparisons, and electoral summaries. Open a format page for
its primary interface, the controls page for behavior shared across builders, or the workflow page
for a small composition.

::::{grid} 1 1 2 2
:gutter: 3

:::{grid-item-card} Histogram
:link: histogram
:link-type: doc

How often an integer or continuous outcome occurs across plans.
:::

:::{grid-item-card} Bar plot
:link: bar
:link-type: doc

Totals and threshold counts across a small set of categories.
:::

:::{grid-item-card} Box plot
:link: box
:link-type: doc

Rank-ordered ensemble distributions with benchmark plan overlays.
:::

:::{grid-item-card} Violin plot
:link: violin
:link-type: doc

Distribution shape, skew, and modes at each district rank.
:::

:::{grid-item-card} Scatterplot
:link: scatter
:link-type: doc

Trade-offs between two plan or district statistics.
:::

:::{grid-item-card} Sea-level plot
:link: sealevel
:link-type: doc

Values for one or many plans across ordered categories.
:::

:::{grid-item-card} Seats-votes plot
:link: seats_votes
:link-type: doc

Seat-share response to uniform electoral swing.
:::

:::{grid-item-card} Paintball plot
:link: paintball
:link-type: doc

Many plans or scenarios in vote-share and seat-share space.
:::

:::{grid-item-card} {octicon}`sliders` Shared controls
:link: options
:link-type: doc

Labels, legends, reference lines, axes, and output shared by every statistical builder.
:::

:::{grid-item-card} {octicon}`stack` Statistical workflow
:link: workflow
:link-type: doc

Combine an election summary and an ensemble distribution on a shared figure.
:::
